## 📝 Короткий огляд артефактів

### 1. Аналіз вимог (`01_requirements_analysis.md`)
Проаналізовано специфікацію `[Draft] US11_Guest Viewing Reservation Menu` за міжнародними стандартами інженерії вимог (IEEE 830 / ISO 29148). Виявлено **10 критичних недоліків та прогалин у вимогах**:
1. Несуперечливість термінології: статус `"On Stop"` у вимогах проти `"Out of Stock"` / `"Unavailable"` у UI.
2. Відсутність вимог для негативних статусів сесії (`Cancelled`, `Expired`, `Closed`).
3. Відсутність валідації та лімітів кількості порцій (+1 за клік, макс. кількість).
4. Відсутність опису віджета/панелі кошика гостя (Subcart Drawer/Counter).
5. Відсутність вимоги на Race Condition (страва перейшла в Stop під час вибору).
6. Неоднозначність формату ваги страви (одиниці виміру `g`, пробіли, напої `ml`).
7. Відсутність опису сортування та поведінки порожньої категорії (Empty state).
8. Невизначеність інтерактивності картки (клік по картці для деталей vs швидкий [Pre-Order]).
9. Політика оновлення меню (Polling vs WebSocket vs F5 Refresh).
10. Відсутність вимог щодо верхнього банера резервації (адреса, стіл, час).

### 2. Тест-кейси (`02_test_cases.csv` / `02_test_cases.md`)
Розроблено сьют із **10 тест-кейсів** за офіційним шаблоном таблиці:
* **TC-01:** Категоризація меню (AC 1) — `Passed`
* **TC-02:** Відображення картки страви згідно з Figma (AC 2) — `Failed` *(Bug #2: вага '2000' замість '200 g')*
* **TC-03:** Додавання страви до кошика кнопкою [Pre-Order] (AC 3) — `Passed`
* **TC-04:** Недоступність замовлення страв "Out Of Stock" (усі кнопки недоступних страв заблоковані / сірі) (AC 4) — `Passed`
* **TC-05:** Блокування кліку по тілу недоступної картки (AC 4) — `Passed`
* **TC-06:** Актуальність меню при відкритті / Refresh (AC 5) — `Passed`
* **TC-07:** Перевірка перенаправлення для Cancelled/Expired сесії — `Passed`
* **TC-08:** Сортування страв (Sort by) — `Passed`
* **TC-09:** Інформаційний банер деталей резервації — `Passed`
* **TC-10:** Граматична правильність та узгодженість UI — `Failed` *(Bug #1, Bug #3, Bug #4)*

### 3. Баг-репорти (`03_bug_reports.csv` / `03_bug_reports.md`)
Зафіксовано **4 дефекти**, виявлені на скріншоті реалізованої сторінки:
* **Bug #1 (Minor / Low):** Неузгоджена капіталізація літер (Title Case vs Sentence case): `'Main page'` проти `'Book a Table'`, `'All dishes'` проти `'Main Courses'`.
* **Bug #2 (Minor / Medium):** Одрук у вазі для `Fresh Avocado Toast` — відображається `'2000'` без одиниць виміру замість `'200 g'`.
* **Bug #3 (Minor / Low):** Неузгоджене форматування та пробіли у вазі порцій (`'2000'`, `'350g'`, `'450 g'`).
* **Bug #4 (Trivial / Low):** Невідповідність термінології бейджа вимогам: `'Out Of Stock'` у UI проти `'On Stop'` в AC 4.
